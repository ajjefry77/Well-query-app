## معرفی پروژه

**سامانه واکاوی لایه‌های مکانی** یک اپلیکیشن سازمانی مبتنی بر وب است که امکان جستجو و استعلام پیشرفته از لایه‌های برداری، چاه‌ها و داده‌های چینه‌شناسی را از طریق API سرویس ژئوباکس فراهم می‌کند.

این سامانه برای متخصصان ژئوفیزیک، مهندسان مخزن و کارشناسان اطلاعات مکانی طراحی شده و ابزارهای زیر را در اختیار کاربر قرار می‌دهد:

- **استعلام توصیفی:** ساخت کوئری‌های پیچیده با فیلترهای منطقی AND/OR/NOT
- **استعلام مکانی:** جستجوی شعاعی از یک نقطه مرکزی با فاصله‌یابی دقیق
- **چینه‌شناسی:** نمودار همبستگی لایه‌های زمین‌شناسی بین چاه‌ها
- **نقشه تعاملی:** نمایش داده‌ها بر روی نقشه با ابزارهای ترسیم و اندازه‌گیری
- **خروجی‌گیری:** صادر کردن داده‌ها در ۶ فرمت مختلف

## ویژگی‌های کلیدی

### 🔍 کوئری توصیفی (Attribute Query)
- ایجاد شرط‌های پویا بر اساس فیلدهای واقعی هر لایه
- عملگرهای مقایسه‌ای: `=`, `>`, `<`, `>=`, `<=`, `!=`, `contains`
- گروه‌بندی شرط‌ها با عملگرهای منطقی `AND` / `OR`
- امکان فعال/غیرفعال کردن `NOT` روی هر شرط
- نمایش تعداد نتایج در لحظه برای هر لایه
- ذخیره و بازیابی کوئری‌های نام‌گذاری‌شده (ذخیره در localStorage)

### 📍 کوئری مکانی (Spatial Query)
- جستجوی شعاعی (پیش‌فرض ۳ کیلومتر، قابل تنظیم تا ۲۰,۰۰۰ کیلومتر)
- دو حالت انتخاب مرکز:
  - **انتخاب از نقشه:** کلیک روی نقشه برای انتخاب نقطه دلخواه یا کلیک روی یک ویژگی
  - **انتخاب از فهرست:** انتخاب چاه یا ویژگی از لیست کشویی
- محاسبه فاصله با فرمول هاورساین (Haversine) در سمت کلاینت
- مرتب‌سازی نتایج بر اساس فاصله

### 🪨 نمودار چینه‌شناسی (Stratigraphy Chart)
- نمودار همبستگی لایه‌های زمین‌شناسی بین چاه‌های مختلف
- تنظیمات پویا برای لایه و فیلدهای نقشه‌برداری (ارتفاع سقف، کف، نام لایه)
- انتخاب/حذف تعاملی چاه‌ها
- فیلتر لایه‌های زمین‌شناسی
- خطوط همبستگی بین چاه‌های مجاور
- جدول ضخامت، راهنما و پنل یادداشت

### 🗺️ نقشه تعاملی با دو ارائه‌دهنده
- **Mapbox GL:** نقشه کامل با ابزارهای ترسیم و اندازه‌گیری
- **Leaflet:** نقشه سبک‌تر با لایه‌های مختلف (توپوگرافی، ماهواره‌ای، تاریک)
- تعامل بی‌نقص بین دو ارائه‌دهنده نقشه

### 🛠️ ابزارهای نقشه (Mapbox)
- ترسیم: نقطه، خط، چندضلعی (با رنگ اختصاصی هر ویژگی)
- اندازه‌گیری: طول خط (هاورساین) و مساحت چندضلعی
- نوار وضعیت با نمایش مختصات Lat/Lng و UTM

### 📤 خروی‌گیری داده‌ها (۶ فرمت)
| فرمت | توضیح |
|---|---|
| **GeoJSON** | فرمت استاندارد جغرافیایی |
| **CSV** | فایل متنی با پشتیبانی از UTF-8 BOM برای اکسل |
| **KML** | فرمت Google Earth |
| **KMZ** | KML فشرده‌شده |
| **Shapefile** | فرمت ESRI |
| **DXF** | فرمت AutoCAD |

### 🏗️ پشتیبانی چندلایه
- افزودن/حذف همزمان چندین لایه برداری
- نمایش/پنهان کردن هر لایه به صورت جداگانه
- شرط‌های کوئری مستقل برای هر لایه
- رنگ‌بندی خودکار لایه‌ها با پالت تعیین‌شده
- جدول نتایج تب‌بندی‌شده برای هر لایه

### 📱 طراحی واکنشگرا
- **دسکتاپ:** لایه‌بندی سه‌ستونی (پنل کوئری | نقشه | پنل نتایج)
- **تبلت:** پنل‌های جمع‌شونده
- **موبایل:** برگه پایینی با قابلیت کشیدن و جابه‌جایی تب‌ها
- نقاط عطف: 1240px، 1024px، 760px، 520px، 460px

### 🌓 سیستم تم
- پشتیبانی از تم روشن و تاریک
- تشخیص خودکار ترجیح سیستم (`prefers-color-scheme`)
- ذخیره‌سازی انتخاب در localStorage
- تغییر استایل نقشه بر اساس تم فعال

## راه‌اندازی و نصب

### ۱. کلون کردن پروژه

```bash
git clone <آدرس مخزن>
cd WellQueryApp
```

### ۲. نصب وابستگی‌ها

```bash
npm install
```

### ۳. تنظیم متغیرهای محیطی

فایل `.env.example` را کپی کرده و به `.env` تغییر نام دهید:

```bash
cp .env.example .env
```

سپس مقادیر زیر را پر کنید (جزئیات در بخش [متغیرهای محیطی](#متغیرهای-محیطی)).

### ۴. اجرای سرور توسعه

```bash
npm run dev
```

برنامه در آدرس `http://localhost:5173` قابل دسترسی خواهد بود.

## متغیرهای محیطی

این پروژه از فایل `.env` برای مدیریت تنظیمات استفاده می‌کند:

| متغیر | توضیح | اجباری |
|---|---|---|
| `VITE_API_USER` | نام کاربری API ژئوباکس | ✅ |
| `VITE_API_PASS` | رمز عبور API ژئوباکس | ✅ |
| `VITE_MAPBOX_TOKEN` | توکن دسترسی Mapbox GL | ✅ |
| `VITE_API_BASE` | آدرس پایه API (پیش‌فرض: /api) | ❌ |

> ⚠️ **توجه:** فایل `.env` شامل اطلاعات حساس است و نباید در مخزن کنترل نسخه قرار گیرد. فایل `.gitignore` از ثبت آن جلوگیری می‌کند.

## دستورات توسعه و ساخت

| دستور | توضیح |
|---|---|
| `npm run dev` | اجرای سرور توسعه با بازگذاری داغ و پراکسی API |
| `npm run build` | ساخت نسخه تولید (هدف ES2020، فشرده‌سازی esbuild) |
| `npm run preview` | پیش‌نمایش نسخه تولید به صورت محلی |

### استقرار تولید

پس از اجرای `npm run build`، فایل‌های بهینه‌شده در پوشه `dist/` تولید می‌شوند.

- این فایل‌ها را می‌توان روی هر هاست ایستا (nginx، Apache، Vercel، Netlify و ...) مستقر کرد.
- برای محیط تولید، متغیر `VITE_API_BASE` را روی آدرس کامل API تنظیم کنید یا پراکسی nginx را برای مسیر `/api` پیکربندی نمایید.

## خروی‌گیری داده‌ها

امکان صادر کردن نتایج کوئری در ۶ فرمت مختلف:

- **GeoJSON** — فرمت استاندارد برای استفاده در نرم‌افزارهای GIS
- **CSV** — فایل متنی ساده با پشتیبانی از UTF-8 BOM برای باز شدن صحیح در اکسل
- **KML** — فرمت Google Earth برای مشاهده سه‌بعدی
- **KMZ** — نسخه فشرده‌شده KML
- **Shapefile** — فرمت استاندارد ESRI برای ArcGIS و QGIS
- **DXF** — فرمت AutoCAD برای استفاده در نرم‌افزارهای طراحی

## بهینه‌سازی عملکرد

- **بارگذاری تنبل:** کامپوننت‌های سنگین (نقشه‌ها، مودال‌ها) با `defineAsyncComponent` بارگذاری می‌شوند
- **RequestIdleCallback:** فراخوانی‌های API غیرضروری پس از رسم اولیه اجرا می‌شوند
- **تقسیم باندل:** جداسازی دستی وابستگی‌ها در Vite (vendor-mapbox، vendor-leaflet، vendor-turf، vendor-export، vendor-vue)
- **لغو درخواست‌ها:** استفاده از AbortController برای لغو درخواست‌های در حال اجرا
- **تشخیص دستگاه ضعیف:** غیرفعال کردن انیمیشن‌ها و انتی‌ایلیسینگ در دستگاه‌های ضعیف
- **پشتیبانی از حالت صرفه‌جویی داده:** رعایت `navigator.connection.saveData`

## شرایط و قوانین استفاده

### مالکیت معنوی
تمامی حقوق مادی و معنوی این نرم‌افزار، از جمله ولی نه محدود به کد منبع، طراحی رابط کاربری، اسناد و مستندات، متعلق به **شرکت ساج گستر کاسپین** می‌باشد.

### مجوز استفاده
استفاده از این نرم‌افزار فقط برای اهداف داخلی شرکت ساج گستر کاسپین و شرکت‌های وابسته مجاز است. هرگونه استفاده تجاری، توزیع یا انتشار عمومی بدون مجوز کتبی از شرکت ممنوع است.

### مسئولیت‌ها
- کاربران مسئول حفاظت از اطلاعات ورود و توکن‌های دسترسی خود هستند
