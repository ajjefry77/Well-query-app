# پیگیری مرحله‌ای بررسی GeoBox

تاریخ: ۲۰۲۶-۱۱-۰۳

مبنای کار: گزارش ارسالی کاربر. فایل اصلی RFP و داده‌های واقعی در این مرحله بررسی نشده‌اند؛ وضعیت‌ها تأیید انطباق کامل با RFP نیستند.

## محدودیت‌های قطعی

- کلیدها، مقادیر و فایل‌های env تغییر نمی‌کنند.
- کد بک‌اند، BFF و تغییر قرارداد احراز هویت اضافه نمی‌شود.
- معماری فعلی و قابلیت‌های موجود با اصلاحات محدود حفظ می‌شوند.

## مرحله اول: پایداری اتصال، بارگذاری لایه و منابع نقشه

| مورد | اقدام و وضعیت |
| --- | --- |
| P1-01 احراز هویت | آزاد شدن قفل درخواست توکن در خطای JSON یا تنظیمات ناموجود؛ حفظ کش و دریافت مشترک توکن؛ افزودن تایم‌اوت. انتقال اطلاعات ورود به سرور انجام نشده و معیار مخفی‌بودن اطلاعات ورود در خروجی فرانت حل نشده است. |
| P1-02 API | کنترل لغو پیش از احراز هویت، پس از آن و هنگام خواندن پاسخ؛ یک بار تلاش مجدد برای 401؛ حفظ کد وضعیت و پیام قابل نمایش برای 403، 429 و 5xx؛ عدم تلاش مجدد روی خطاهای دائمی دریافت عوارض. |
| P1-02 صفحه‌بندی | حفظ پارامترهای API موجود؛ اعلام خطا هنگام رسیدن به سقف به جای ارائه نتیجه ظاهراً کامل؛ کنارگذاشتن صفحات پیش‌دریافت‌شده پس از اولین صفحه کوتاه؛ تطبیق با رفتار API واقعی هنوز لازم است. سقف فعلی عوارض ۵۰ صفحه × ۲۰۰۰ رکورد است. |
| P1-03 چرخه عمر | لغو فریم‌های زمان‌بندی‌شده رندر و هایلایت هر دو موتور نقشه؛ لغو بارگذاری لایه‌ها و محاسبات رابطه مکانی هنگام خروج از scope. بررسی تعاملی همه ابزارهای نقشه باقی است. |
| P1-04 هماهنگی وضعیت | جلوگیری از بازگشت لایه حذف‌شده، تقدم آخرین انتخاب دسته‌ای، جلوگیری از بازگشت اطلاعات پس از پاک‌سازی و حفظ نشانگر بارگذاری هنگام درخواست‌های همزمان. |
| P5 پیش‌نیاز تست | تست با runner داخلی Node و داده ساختگی؛ بدون نصب وابستگی یا اتصال به API واقعی. |

## معیار پذیرش و روش بررسی

- ورودی: درخواست‌های همزمان، پاسخ دیرهنگام، پاسخ نامعتبر، لغو و وضعیت‌های خطای HTTP.
- خروجی: نتیجه فقط برای انتخاب معتبر فعلی؛ خطای قابل نمایش بدون پاک‌شدن شرط‌های قبلی؛ آزادشدن نشانگر بارگذاری پس از اتمام کارهای جاری.
- فایل‌های مؤثر: `useGeoboxApi.js`، `useWellQuery.js` و cleanup دو کامپوننت نقشه.
- تست‌های بازگشت: `npm test`؛ شامل توکن، خطاهای HTTP، صفحه‌بندی، حذف/پاک‌سازی/تعویض لایه، بارگذاری همزمان و خروج از scope.
- بررسی ساخت: `npm run build`.
- اجرای موفق تست و build، جای بررسی تعاملی مرورگر و تأیید سرویس واقعی را نمی‌گیرد.

نتیجه اجرای این مرحله: هر ۲۵ تست موفق، ساخت production موفق و `git diff --check` بدون خطا بود. هشدار قبلی بزرگی بسته Mapbox در build همچنان وجود دارد. هیچ فایل env یا تنظیمات بک‌اند تغییر نکرد.

## ترتیب ادامه گزارش

1. تکمیل بررسی تعاملی چرخه عمر نقشه و تطبیق صفحه‌بندی با سرویس واقعی.
2. بررسی صحت Attribute/Spatial Query، محاسبات Correlation Chart و CRS با نمونه‌های مرجع.
3. توسعه قابلیت‌های فرانت موردنیاز Contour و Thematic پس از تعریف ورودی و معیار صحت.
4. تکمیل خروجی‌ها، چاپ، دسترس‌پذیری و واکنش‌گرایی با تست مرتبط.
5. بازآرایی تدریجی کامپوننت‌ها پس از تثبیت رفتار فعلی.

آرشیو سازمانی، RBAC، نسخه‌بندی سمت سرور و انتقال credentialها به بک‌اند در محدودیت فعلی پیاده‌سازی نمی‌شوند. سند ارسالی تعریف دقیق کافی برای تأیید همه قابلیت‌های تخصصی RFP ندارد.
